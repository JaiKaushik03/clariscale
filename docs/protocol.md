# Protocol

Consent and a non-identifying participant code precede collection. Do not collect names, email, birth dates or student IDs. Participation is voluntary; the application is not a diagnostic or treatment service. Fifteen minutes was a target, not a measured guarantee.

A always presents PSS-10 Q1–Q5 as multiple choice. B always presents Q6–Q10 as typed answers. Each block stays in ascending order and appears once. Only AB/BA condition sequence varies. Ten SUS statements follow each condition.

Clear frequency language maps to 0 Never, 1 Almost never, 2 Sometimes, 3 Fairly often, 4 Very often. Long phrases consume their text before shorter matches: `almost never` before `never`, `very often` before `often`. Curly apostrophes normalize to straight apostrophes and text lowercases. Unknown, uncertain, explicitly negated and conflicting-category text abstains. It is a limited lexicon, not general semantic understanding.

One neutral clarification is permitted. Unresolved text receives the original five choices. Keep initial, post-clarification and fallback categories separate. Fallback is not automatic success. No microphone, camera, runtime LLM or emotion classifier interprets answers.

The same agent and programmed cue policy run in A and B. Institutional access may require FIU/eEVA account and network permissions.

Completion: save locally, download own XLSX, acknowledge download, display clickable/copyable configured manual-upload link, acknowledge upload, finish. Acknowledgments cannot prove file arrival. Qualtrics and eEVA are independent collection systems; neither automatically uploads to the other.
